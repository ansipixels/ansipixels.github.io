# Ansipixels

Welcome to **Ansipixels** - a powerful terminal UI library that brings beautiful ANSI pixel art, games, and utilities to your terminal!

## What is Ansipixels?

Ansipixels is a Go library for creating rich, interactive terminal applications with pixel-perfect graphics using ANSI escape codes. It enables developers to build stunning visual experiences directly in the terminal.

## Getting Started

Each project includes detailed installation and usage instructions in their respective repositories. Most can be installed easily with Go:

```bash
go install fortio.org/[project]@latest
```
